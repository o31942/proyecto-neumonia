🩺 El Reto Clínico Radiológico

  • Alta variabilidad interobservador: Infiltrados pulmonares incipientes son difíciles de distinguir visualmente.
  • Soporte dual de formatos: Estándar médico DICOM (.dcm) de 16-bits con calibración hospitalaria y formatos comunes JPEG / PNG.
  • Manejo de interpretación fotométrica: Conversión robusta de MONOCHROME1 (huesos negros) a MONOCHROME2 (huesos blancos).
  • Prohibición de "Cajas Negras": Se exige explicabilidad espacial (Grad-CAM) para auditoría clínica.

⚙️ Reglas Estrictas de Ingeniería UAO

  • Cero raw pip: Prohibido pip install y requirements.txt. Gestión determinista con uv y uv.lock.
  • Cero Notebooks sucios: Prohibido versionar .ipynb en producción. Código modular puro en layout src/.
  • Contratos matemáticos formales: Asertos explícitos de finitud (sin NaN/Inf) y rango cerrado [0.0, 1.0].
  • Inferencia CPU reproducible: Contenedor Docker liviano sin requerir GPUs NVIDIA.
🗣️ Qué decir: "Enfatizar que el sistema fue concebido como un producto de ingeniería y no como un script experimental. Destacar el soporte nativo tanto para radiografías DICOM hospitalarias como para JPEG."

🕹️ Controlador (Controller)

  • read_img.py: Responsable único de leer DICOM y JPEG, retornando array 2D uint8 (H, W).
  • preprocess_img.py: CLAHE adaptativo, resize (512, 512) y asertos de contrato formal.
  • integrator.py: Orquestador desacoplado con inyección de dependencias y modo CLI.

🧠 Modelo (Model & XAI)

  • load_model.py: Carga artefacto WilhemNet86.h5 o inicializa arquitectura funcional compatible en CPU.
  • Inferencia probabilística con umbral de decisión ajustable.
  • grad_cam.py: Cálculo de gradientes en tf.GradientTape sobre la capa conv_last y superposición Jet.

🖥️ Vista (View)

  • app.py: Aplicación interactiva en Streamlit.
  • Comparativa tripartita: Original vs CLAHE vs Grad-CAM superpuesto.
  • Ajuste en vivo de umbrales clínicos y opacidad.
  • Alertas diagnósticas médicas y selector de muestras reales.
🗣️ Qué decir: "Destacar la Alta Cohesión y Bajo Acoplamiento: cambiar el modelo convolucional no altera la interfaz de usuario ni los lectores; cada archivo tiene una única responsabilidad matemática o de presentación."

🔬 Algoritmo CLAHE Adaptativo

  • ¿Por qué CLAHE? La ecualización global quema las altas luces. CLAHE opera por cuadrículas contextuales de (8, 8).
  • Parámetro de corte: clipLimit=2.0 previene la amplificación de ruido de alta frecuencia en el parénquima.
  • Resize estandarizado: Interpolación bilineal adaptativa a (512, 512) px.
  • Normalización precisa: Conversión a float32 en escala continua [0.0, 1.0].

🛡️ Asertos e Invariantes Matemáticos

  • assert tensor.shape == (1, 512, 512, 1)
  • assert tensor.dtype == np.float32
  • assert np.isfinite(tensor).all()  ➡️ ¡Cero NaN y cero Infinitos!
  • assert 0.0 <= tensor.min() and tensor.max() <= 1.0
  • Impacto: Elimina errores silenciosos en capas de Batch Normalization antes de gastar recursos de inferencia.
🗣️ Qué decir: "El profesor valora mucho los asertos de contrato. Explicar que sin 'assert np.isfinite', un píxel corrupto en un DICOM causaría propagación silenciosa de NaN en toda la red neuronal."

⚡ Arquitectura WilhemNet86 (CPU)

  • Red neuronal convolucional profunda optimizada para CPU (inferencia < 50 ms).
  • Bloques convolucionales con Batch Normalization y ReLU.
  • Capa objetivo de explicabilidad: conv_last (256 canales con resolución espacial).
  • Global Average Pooling + Dropout (0.3) + Clasificación Sigmoide binaria.

🔥 Algoritmo Grad-CAM

  • Paso 1: tf.GradientTape extrae los gradientes de la clase con respecto a los mapas de conv_last.
  • Paso 2: Global Average Pooling de los gradientes para obtener los pesos de importancia de cada filtro.
  • Paso 3: Combinación ponderada + activación ReLU (solo importancias positivas).
  • Paso 4: Fusión alfa-blending: 40% mapa térmico Jet + 60% radiografía original.
🗣️ Qué decir: "Resaltar que Grad-CAM permite al radiólogo auditar si el modelo diagnosticó neumonía por ver consolidaciones en los pulmones, o si fue engañado por artefactos externos como marcapasos o electrodos."
